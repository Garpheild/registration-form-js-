
# Часть 1 — Нативные технологии

Форма авторизации на чистом HTML, CSS и JS.

## Запуск

Откройте `index.html` в браузере.

Тестовые данные: `admin@mail.ru` / `secret123`



## HTML

- **Шапка и подвал** — теги `<header>` и `<footer>`
- **Форма** — кнопки соцсетей, поля логина и пароля, чекбокс «Сохранять сессию», кнопка «Войти»
- **Семантические теги** — `<header>`, `<main>`, `<section>`, `<footer>`, `<form>`, `<label>`
- **Accessibility** — `<label for="...">` у каждого поля, `required` и `minlength` для валидации браузером, `autocomplete` для подсказок


## Почему Flexbox

Форма — это элементы друг под другом, Flexbox удобен для вертикального расположения. Центрирование формы — `display: flex` + `justify-content: center`. Grid не нужен, сетки нет.


## CSS

- **Переопределение стилей** — `body`, `h1`, `h2`, `p`, `button`, `label`
- **Transition** — рамка поля при фокусе, фон кнопки при наведении
- **Keyframe** — `shake` анимация при ошибке
- **Media queries** — `480px` для мобильных (кнопки в столбик, меньше отступы)
- **Селекторы:**
  - Класс: `.card`, `.btn`
  - Атрибут: `.input.error`, `.input.success`
  - ID: `#submitBtn`, `#loginForm`
  - Тег: `body`, `h1`, `footer`
  - Псевдоселекторы: `:hover`, `:focus`, `:disabled`, `::placeholder`


## JS

- **Валидация** — regex для email/телефона, пароль минимум 6 символов
- **Сообщения** — красный текст при ошибке, зелёная рамка при правильном вводе
- **Проверка данных** — `admin@mail.ru` / `secret123`, сравнение через `===`
- **Сохранение** — `localStorage`, потому что данные сохраняются после закрытия браузера. Храню только логин, пароль не сохраняю — небезопасно
- **Обработчики** — `submit`, `input`, `click`
- **Функции** — именованные (`function`) для валидации, стрелочные (`=>`) для коротких действий. Стрелочные проще для однострочных задач.
